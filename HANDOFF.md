## Что это

На вход маршрут — на выходе упорядоченный по километражу список знаковых мест
вдоль него: история, архитектура, инженерия, современная культура. Плюс районы,
которые маршрут пересекает, и профиль их «настроения». По клику на объект —
подробности и, опционально, AI-исследование: кто здесь жил, что случилось,
что было раньше, откуда название улицы.

Стадия: **работающий MVP-прототип**, все данные настоящие, фейков нет.

## Запуск

```bash
cd /home/sntx/2rist && ./run.sh
```

Откроется http://127.0.0.1:8080. Зависимости в `.venv`, ключ Gemini в `.env`
(в `.gitignore`, в репозиторий не попадал — проверено).

## Что работает

- Маршрут через точки A→B→C: клик по карте, перетаскивание, подсказки адресов,
  определение страны по IP, режимы пешком и на машине.
- Сбор объектов из OSM (Overpass), Wikidata (SPARQL), Википедии (геопоиск),
  склейка дублей, ранжирование, разрежение по километражу.
- Категории: история, архитектура, памятники, религия, музеи, искусство,
  современная культура, сообщества, ночная жизнь, парки, промышленность,
  инженерия, транспорт, социальное.
- Районы вдоль маршрута с профилем «настроения» в духе Hoodmaps, но
  вычисленным из состава заведений.
- Двухфазная выдача: черновик за 2-4 с, полный ответ следом.
- AI-обогащение по клику: люди, события, что было раньше, этимология улицы,
  с проверкой источников и отдельным полем для непроверенного.

Проверено на двух городах: Москва (Кропоткинская → Патриаршие) и Тбилиси
(площадь Свободы → Мост Мира, улица Аны Каландадзе).

## Что не работает и известные слабости

1. **Первый запрос в новом районе непредсказуем.** Публичный Overpass на
   одном и том же запросе давал 2.1 с, 21 с и 65 с подряд. Это очередь на их
   стороне, оптимизацией фильтров не лечится. **Главный риск для демо.**
2. **WDQS в полной стадии** добавляет 4-30 с. Вынесен из быстрой стадии,
   но в полной остаётся.
3. **Значимость меряется числом языковых версий Википедии.** Проходной особняк
   и Патриаршие пруды получают близкий скор. Лечится просмотрами страниц.
4. **Тексты только из Википедии.** У объектов без статьи в карточке пусто,
   пока не нажать AI.
5. **Районы иногда рвутся**: маршрут идёт по границе полигонов, и на стыке
   появляется разрыв в километраже.
6. **AI-слой медленный** — 20-60 с на объект, только по клику. Предзагрузки
   по приближению нет.

## Что делать дальше, по приоритету

1. **Локальный Overpass в докере на города демо.** Тбилиси около 30 МБ,
   Москва около 150 МБ, docker установлен. Двадцать минут настройки убирают
   главный риск демо и делают первый запрос предсказуемым.
2. **Инкрементальный кэш Wikidata** — таблица `qid → sitelinks, метки,
   свойства` в SQLite с TTL 90 дней, наполняется по мере запросов плюс
   фоновый прогрев города. 2-3 часа работы. Полный дамп (20-34 часа) — только
   когда пойдём в масштаб.
3. **Просмотры страниц Википедии** вместо sitelinks в скоринге — месячным
   дампом, не через REST.
4. **Новые структурные слои** вместо AI там, где данные уже есть: мемориальные
   доски (`memorial=plaque` — «здесь жил»), этимология улиц
   (`name:etymology:wikidata`), Wikidata P551 и P937 (где человек жил
   и работал), lifecycle-теги (`demolished:building` — что было раньше).
5. **Предрасчёт по H3-ячейкам** — финальная форма: запрос маршрута
   превращается в пространственный join.

## Что нужно знать, прежде чем трогать код

Эти вещи стоили времени и неочевидны — подробности в
[docs/DECISIONS.md](docs/DECISIONS.md):

- К Overpass ходить **строго по одному запросу**, иначе 429 и ретраи на минуты.
- `around` вдоль длинной ломаной Overpass не переживает — только bbox-чанки.
- requests-cache **не кэширует Википедию**, пока не отключены куки.
- Полные факты Wikidata для сотен объектов — десятки секунд, поэтому они
  грузятся только для одного открытого объекта.
- Современному слою нужна **квота** в выдаче: у хакспейса нет статьи
  в Википедии, и по общей формуле он не всплывёт никогда.

## Инфраструктура

- Репозиторий: `sntxerror/2rist` (приватный), ветка `main`.
- Ключ Gemini: проект gcloud **Pi Agent** (`gen-lang-client-0054709975`),
  ключ ограничен `generativelanguage.googleapis.com`, лежит в `.env`.
  Дневной потолок вызовов — `TRIST_AI_DAILY_LIMIT`, по умолчанию 300.
- HTTP-кэш: `data/cache/http.sqlite`, сейчас около 20 МБ, TTL 14 дней.
  Удаление кэша безопасно — просто первый запрос будет медленным.
- Машина: 8 ядер, 31 ГБ RAM, 425 ГБ свободно. Есть docker, duckdb, codex,
  gemini CLI. Нет postgres, osm2pgsql, osmium.
